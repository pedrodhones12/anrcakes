# Ane Cakes Fair — site de apresentação

Site one-page responsivo criado a partir do portfólio visual e do Projeto Ane Cakes Fair 2026.

Arquivos:
- index.html
- styles.css
- script.js
- assets/ — imagens extraídas do portfólio e imagem de referência da identidade visual

Para publicar:
1. Abra `index.html` localmente para visualizar.
2. Para colocar no ar, envie a pasta para GitHub Pages, Netlify, Vercel ou outro host estático.
3. O botão de contato usa o WhatsApp da apresentação do projeto: (73) 99180-2061.
